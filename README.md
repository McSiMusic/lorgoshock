# Lorgoshock: Open to Work

> **[Играть в демо →](https://mcsimusic.github.io/lorgoshock/)**

Автономная пошаговая 4X-стратегия: Лоргошки против ИИ-корпорации. Захватывай компании и майнинг-фермы, исследуй карту, нанимай юнитов и превращай токены в карьерный рост.

## Как играть

1. Выбери фракцию и размер карты (до 32 × 32).
2. Выбери своего юнита и щёлкни по голубой клетке, чтобы переместить его. Щёлкни по видимому вражескому юниту, чтобы атаковать.
3. Захватывай нейтральные базы, собирай ресурсы и находи кофейни.
4. Нажми на свой город, чтобы тренировать юнита в гарнизоне. Изучай технологии и жми **«Конец хода»**.
5. Победи, захватив все компании и майнинг-фермы на карте.

Игровой мир, правила и ИИ работают в Web Worker прямо в браузере. Игра не требует аккаунта, бэкенда или сетевого подключения после загрузки страницы. URL с сидом матча можно отправить другу.

## Разработка

Нужен Node.js 20.9 или новее.

```bash
npm ci
npm run dev
```

```bash
npm run typecheck
npm test
npm run build
```

Next.js экспортирует статический сайт в `out/`. GitHub Actions автоматически проверяет типы, запускает тесты, собирает проект и публикует его в GitHub Pages при обновлении ветки `main`.

## Технологии

- Next.js App Router, React, TypeScript, статический экспорт
- Redux Toolkit — состояние интерфейса и игрового поля
- PixiJS — интерактивная карта, объекты и туман войны
- Web Worker — игровая логика, процедурная генерация поля и Utility AI
- Vitest — тесты правил, боя, дохода, путей и исследования карты
